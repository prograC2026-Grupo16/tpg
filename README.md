# Trabajo Práctico Grupal de Programación C, FI, UNMdP, Argentina
Proyecto de Software embarcado de una nave interstelar tripulada.

- Código fuente (paquete con todas las clases) en la carpeta /software/src/main/java/tpgProgra2026/
- Informe en carpeta raíz /
- Consigna y demás documentos en la carpeta raíz /


## Cómo ejecutar (desde el IDE)

Hacer *Run* sobre `tpgProgra2026.Main` (IntelliJ, Eclipse o VS Code). Abre el Login y, al ingresar, la simulación.
Usuarios: registrar desde el Login o desde `MainVistaLogin` (Ana/1234, pablo/123, matias/12).
La base `usuarios.db` se ubica en la carpeta `software/` (ver `usuarios/RutaBaseDatos`), sin rutas absolutas.
